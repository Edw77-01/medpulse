# MedPulse • Plataforma Web y Móvil de Estudio Médico

Plataforma formativa interactiva para estudiantes de medicina, diseñada para optimizar la preparación de exámenes clínicos, rotaciones hospitalarias y asignaturas básicas.

---

## 🚀 Funcionalidades Principales (PRD)

1. **Cuestionarios Interactivos (Banco de Preguntas)**:
   - Selección múltiple de casos y preguntas clínicas.
   - Calificación visual inmediata (verde / rojo).
   - Explicaciones pedagógicas detalladas de por qué cada opción es correcta o distractor.
   - Perlas de examen y consejos de alta retención.

2. **Simulador de Casos Clínicos Educativos**:
   - Pacientes ficticios con antecedentes y factores de riesgo.
   - Constantes vitales monitorizadas en tiempo real con alertas fisiológicas.
   - Pestañas interactivas: *Anamnesis y Exploración*, *Laboratorios y Pruebas*, y *Toma de Decisiones Clínicas*.
   - Razonamiento formativo guiado paso a paso.

3. **Dashboard de Seguimiento del Progreso**:
   - Porcentaje global de aciertos dinámico.
   - Desglose de dominio por especialidad médica (Farmacología, Cardiología, Neumología, Pediatría, Medicina Interna).
   - Historial de intentos recientes y contador de racha activa de estudio.

4. **Repaso Personalizado y Puntos Débiles**:
   - Detección automática de temas con mayor tasa de error.
   - Recomendaciones de estudio de alto rendimiento.
   - Generador de tests enfocados en puntos débiles con un solo clic.
   - Tarjetas mnemotécnicas (flashcards) interactivas.

5. **Tutor de Inteligencia Artificial Médico**:
   - Chat interactivo para consultas clínicas.
   - Respuestas estructuradas con fisiopatología, reglas mnemotécnicas y preguntas de autoevaluación.
   - Sugerencias rápidas con temas frecuentes de examen.

---

## 📱 Experiencia Móvil (Celulares) y Escritorio
- **Diseño Adaptable (Responsive)**:
  - En computadoras: Barra lateral completa y espacio de trabajo expandido.
  - En celulares: Barra inferior de navegación táctil fija (*Bottom Bar*), botones con zona táctil cómoda y textos legibles sin zoom.
- **Persistencia**: El progreso y estadísticas se guardan en el navegador (`LocalStorage`) de forma automática.

---

## ⚠️ Aviso de Uso Académico
Esta aplicación tiene propósitos estrictamente formativos y educativos para estudiantes de medicina. No diagnostica enfermedades ni recomienda tratamientos para pacientes reales ni reemplaza la formación docente hospitalaria.
